Sobre nosotros

Somos un equipo de estudiantes de UNIR. Creamos este blog como actividad de la asignatura Aplicaciones en Red para practicar HTML y CSS.

Integrantes del equipo

  • Julio Cesar Godoy Orrego
  • María Paola Galeano Correa

Por qué este tema

Elegimos la robótica y la inteligencia artificial porque son dos tecnologías que ya forman parte de nuestra vida diaria (asistentes de voz, aspiradoras robot, fábricas automatizadas) y queríamos entender mejor cómo funcionan.

Cómo está hecho este blog

  • HTML5 para la estructura, usando etiquetas semánticas como <header>, <nav>, <main>, <article> y <footer>.
  • CSS3 en un único archivo compartido, con variables, Flexbox, CSS Grid y media queries para que se adapte a móviles.
  • Publicado como sitio estático en GitHub Pages.
